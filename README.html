🎨 Processing Web (スタンドアローン版) 自宅自習用

この環境は、インターネット接続やソフトウェアのインストールなしに、WebブラウザだけでProcessing (p5.js) のプログラミング・実行・保存ができる学習用ツールです。

🚀 エディタを起動する (index.html を開く)

🚀 はじめかた

Step 1: 起動
フォルダ内の index.html をダブルクリックして開きます（Google Chrome, Microsoft Edge, Safari などに対応）。
Step 2: コード作成 & 実行
左側の黒いエディタにコードを書き、上部の 「▶ 実行」 ボタン（または Ctrl + Enter）を押すと右側の画面に描画されます。
Step 3: 保存（課題の提出）
上部の 「💾 保存」 ボタン（または Ctrl + S）を押すと、.pde ファイルとしてダウンロードされます。このファイルを課題として提出できます。

⌨️ 便利なショートカットキー

操作 Windows macOS
コードの実行 Ctrl + Enter Cmd (⌘) + Enter
ファイルの保存 (.pde) Ctrl + S Cmd (⌘) + S

📂 保存したプログラムを再開するには

  • 上部の 「📂 開く」 ボタンを押して以前保存した .pde ファイルを選択してください。
  • または、パソコン上の .pde ファイルを エディタ画面に直接ドラッグ＆ドロップ しても開くことができます。
⚠️ 安心機能（自動下書き保存）
うっかり保存する前にブラウザを閉じてしまっても、次回 index.html を開いたときに直前のコードが自動復元されます。ただし提出用ファイルが必要な場合は、必ず「💾 保存」を押して .pde ファイルをダウンロードしてください。

💡 よくある質問

Q. 学校の演習室と同じコードが動きますか？
A. はい。void setup() や size(400, 400); などの構文は自動的に変換されてそのまま動きます。

Q. 無限ループで画面が固まってしまったら？
A. 上部の 「■ 停止」 ボタンを押せば、強制的に実行を中断してリセットできます。
