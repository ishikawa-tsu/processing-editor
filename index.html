ℹ️ 使い方ガイド & ショートカット

🎨 Processing Web (スタンドアローン版) は、サーバーやインターネット接続なしで動く学習用エディタです。

⌨️ ショートカットキー

実行Ctrl + Enter (Mac: Cmd + Enter)
保存 (.pde)Ctrl + S (Mac: Cmd + S)

📂 ファイルの保存と再開

  • 保存: 「💾 保存」ボタンを押すと、PCのダウンロードフォルダに .pde 形式で保存されます。
  • 読み込み: 「📂 開く」ボタンでファイルを選択するか、エディタ領域にファイルをドラッグ＆ドロップしてください。
  • 自動復元: ブラウザを誤って閉じても、直前に編集していたコードは自動で復元されます。

💡 注意事項

  • void setup(), size(400, 400); などの Java 風構文は自動で変換されて実行されます。
  • 演習室システムと同じく、画像読み込み（loadImage 等）は使用できません。
